# Text Analysis Using Python

## Project Overview

Text Analysis is a Python program that analyzes a given paragraph and calculates the word count, character count, vowel count, and frequency of repeated words.

The project demonstrates basic text-processing techniques that are useful in Natural Language Processing (NLP).

## Objective

To practise basic text processing using Python and understand how textual information can be converted into useful numerical statistics.

## Features

- Counts words in a given text.
- Counts characters, including spaces and punctuation.
- Counts occurrences of vowels.
- Identifies repeated words and their frequencies.
- Calculates the number of unique words.
- Supports sample text and custom user input.

## Technologies Used

- Python 3
- Regular expressions (`re`)
- `collections.Counter`
- Visual Studio Code
- GitHub

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the folder in VS Code.
4. Open a terminal.
5. Execute:

`python text_analysis.py`

On Windows, you can also try:

`py text_analysis.py`

## Text Processing Rules

- Word counting is case-insensitive.
- Punctuation is ignored when extracting words.
- Character counting includes spaces and punctuation.
- Vowel counting includes a, e, i, o, and u.
- A repeated word is one that occurs more than once.
